01 / What is AI?

AI doesn't follow rules.
It discovers them.

Traditional software runs on explicit instructions you write. AI flips this: instead of telling it what to do, you show it thousands of examples and it learns the pattern on its own.

👶

Analogy: Teaching a child to recognise dogs. You don't write rules like "4 legs AND fur AND tail". You just show 1,000 photos labelled "dog" or "not dog". The child figures out the pattern. AI works the same way.

💡 The key shift

Traditional code: IF ears AND fur THEN dog
Machine Learning: show examples → algorithm discovers the IF-THEN itself.

02 / The Building Block

One neuron,
one decision.

Every AI system — from image recognisers to ChatGPT — is built from the same tiny unit: the artificial neuron. It takes inputs, multiplies each by a learnable weight, sums them up, and fires an output.

⚖️

Analogy: A judge deciding a verdict. Each piece of evidence (input) has a weight of importance. The judge sums the weighted evidence, and if it crosses a threshold, they rule "guilty" (neuron fires). Weights = the judge's learned experience.

💡 The math in plain English

Output = Activation( x₁·w₁ + x₂·w₂ + x₃·w₃ + bias )

03 / Layers of Intelligence

Stack neurons.
Get intelligence.

One neuron can only detect one simple pattern. But connect them in layers — each layer feeding the next — and early layers detect simple things like edges, middle layers find shapes, and deep layers recognise objects.

🏭

Analogy: A factory assembly line for image understanding. Worker 1 spots edges. Worker 2 combines edges into curves. Worker 3 combines curves into features like "nose" or "wheel". Worker 4 identifies the final object.

💡 Why depth matters

Each layer learns more abstract features. That's why "deep" learning — many layers — can recognise faces, understand speech, and generate text. Watch the signal propagate →

04 / How AI Learns

Make a guess.
Measure the mistake.
Adjust. Repeat.

AI learning is a feedback loop. The network makes a prediction, we measure how wrong it was (the "loss"), figure out which weights caused the mistake, and nudge those weights to do better next time.

🎯

Analogy: Learning to throw darts. You throw (predict), see how far you missed (loss), adjust your arm angle (weights), and throw again. After 10,000 throws, you're hitting the bullseye consistently.

1
Feed Data

Send a batch of labelled examples into the network

2
Forward Pass → Prediction

Network processes inputs through all layers to produce output

3
Measure Loss

Compare prediction to correct answer. Calculate how wrong it was.

4
Backpropagation

Error flows backward. Compute how each weight contributed to the mistake.

5
Update Weights

Nudge every weight in the direction that reduces loss. Repeat from step 1.

Training loop — watch loss decrease
05 / Finding the Minimum

Roll downhill
until you find
the valley.

Gradient Descent is the algorithm that minimises the loss. It calculates which direction is "downhill" on the loss surface, then takes a step in that direction. Repeat until you reach the lowest point (minimum loss).

🏔️

Analogy: You're blindfolded on a hilly landscape trying to find the valley. You feel the slope under your feet (gradient) and take a small step downhill. Do this repeatedly and you'll eventually reach the lowest point.

💡 The Learning Rate problem

Step too small: takes forever to reach the bottom.
Step too big: you overshoot the valley and bounce around.

06 / Learning Styles

Three ways machines learn

Not all AI systems learn the same way. Depending on what data you have and what problem you're solving, you'll choose a different learning paradigm.

👩‍🏫

Supervised Learning

Learn from labelled examples. A teacher provides both the question and the correct answer. The model learns to map inputs → outputs.

Input: photo of cat
Label: "cat" ✓
Input: photo of dog
Label: "dog" ✓
→ Model learns the pattern
Spam filters, Medical diagnosis
🔍

Unsupervised Learning

No labels provided. The algorithm discovers hidden structure and patterns in the data entirely on its own.

Input: 1 million songs
No labels given
→ Model discovers genres:
Group A, B, C, D...
Customer grouping, Topic modelling
🎮

Reinforcement Learning

An agent learns by interacting with an environment, receiving rewards for good actions and penalties for bad ones — like training a dog with treats.

Agent takes action
+10 reward (goal reached)
-1 reward (wall hit)
→ Agent learns optimal path
AlphaGo, Self-driving, Robotics
