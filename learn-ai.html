01 / What is AI?

AI doesn't follow rules.
It discovers them.

Traditional software runs on explicit instructions you write. AI flips this: instead of telling it what to do, you show it thousands of examples and it learns the pattern on its own.

👶

Analogy: Teaching a child to recognise dogs. You don't write rules like "4 legs AND fur AND tail". You just show 1,000 photos labelled "dog" or "not dog". The child figures out the pattern. AI works the same way.

💡 The key shift

Traditional code: IF ears AND fur THEN dog
Machine Learning: show examples → algorithm discovers the IF-THEN itself.

02 / The Building Block

One neuron,
one decision.

Every AI — from image recognisers to ChatGPT — is built from the same tiny unit: the artificial neuron. It takes inputs, multiplies each by a learnable weight, sums them up, and fires an output.

⚖️

Analogy: A judge deciding a verdict. Each piece of evidence (input) has a weight of importance. The judge sums the weighted evidence, and if it crosses a threshold, they rule "guilty" (neuron fires). Weights = the judge's learned experience.

💡 The math in plain English

Output = Activation( x₁·w₁ + x₂·w₂ + x₃·w₃ + bias )

03 / Layers of Intelligence

Stack neurons.
Get intelligence.

One neuron can only detect one simple pattern. But connect them in layers — each layer feeding the next — and early layers detect edges, middle layers find shapes, and deep layers recognise objects.

🏭

Analogy: A factory assembly line for image understanding. Worker 1 spots edges. Worker 2 combines edges into curves. Worker 3 combines curves into features. Worker 4 identifies the final object.

💡 Why "deep" learning?

Each layer learns more abstract features. That's why "deep" learning — many layers — can recognise faces, understand speech, and generate text. Watch the signal propagate →

04 / How AI Learns

Make a guess.
Measure the mistake.
Adjust. Repeat.

AI learning is a feedback loop. The network predicts, we measure how wrong it was (the "loss"), figure out which weights caused the mistake, and nudge those weights to do better next time.

🎯

Analogy: Learning to throw darts. You throw (predict), see how far you missed (loss), adjust your arm angle (weights), and throw again. After 10,000 throws, you hit the bullseye consistently.

1
Feed Data

Send a batch of labelled examples into the network

2
Forward Pass

Network processes inputs through all layers to produce output

3
Measure Loss

Compare prediction to correct answer — how wrong were we?

4
Backpropagation

Error flows backward; compute how each weight contributed to the mistake

5
Update Weights

Nudge every weight in the direction that reduces loss. Repeat.

05 / Finding the Minimum

Roll downhill
until you find
the valley.

Gradient Descent minimises the loss. It calculates which direction is "downhill" on the loss surface, then takes a step in that direction. Repeat until you reach the minimum.

🏔️

Analogy: Blindfolded on a hilly landscape, trying to find the valley. You feel the slope under your feet (gradient) and take a small step downhill. Do this repeatedly and you'll reach the lowest point.

💡 The Learning Rate problem

Step too small → takes forever. Step too big → overshoot the valley and bounce around.

06 / Learning Styles

Three ways machines learn

Not all AI systems learn the same way. Depending on what data you have and what problem you're solving, you'll choose a different learning paradigm.

👩‍🏫

Supervised Learning

Learn from labelled examples. A teacher provides both the question and the correct answer. The model learns to map inputs → outputs.

Input: photo of cat
Label: "cat" ✓
→ Model learns the pattern
Spam filters · Medical diagnosis
🔍

Unsupervised Learning

No labels provided. The algorithm discovers hidden structure and patterns in the data entirely on its own.

Input: 1 million songs
No labels given
→ Discovers genres naturally
Customer grouping · Topic modelling
🎮

Reinforcement Learning

An agent learns by interacting with an environment, receiving rewards for good actions and penalties for bad ones — like training a dog with treats.

Action taken → +10 reward
Bad action → -1 penalty
→ Learns optimal policy
AlphaGo · Self-driving · ChatGPT RLHF
07 / Tokens & Tokenization

LLMs don't read
words. They read
tokens.

Before processing text, an LLM breaks it into "tokens" — chunks that can be whole words, parts of words, or single characters. "tokenization" becomes ["token", "ization"]. Understanding tokens explains context windows, costs, and quirky model behaviours.

🎵

Analogy — Sheet music: A musician reads notes and chords — pre-packaged sound units. They don't think in individual vibrations. Tokens are the "notes" of language for an LLM. Common words = one note. Rare words get broken into parts.

💡 Why tokens matter

Context window: GPT-4 handles 128,000 tokens (~96,000 words) per conversation.
Cost: API pricing is per token — long prompts = higher cost.
Quirks: LLMs struggled with "9.11 vs 9.9" because numbers are tokens, not math.
Rule of thumb: ~1 token ≈ ¾ of an English word.

08 / Embeddings & Meaning

Words as
coordinates in
meaning-space.

Before an LLM processes a token, it converts it into an embedding — a list of hundreds of numbers (a vector) representing its meaning. Similar words have similar vectors, which is how AI understands context and finds related concepts.

🗺️

Analogy — GPS coordinates: "Paris" and "London" are different cities but close on a map. "Paris" and "Jupiter" are far apart. Embeddings are GPS coordinates on a "map of meaning" — similar concepts cluster together, distant ones are far apart.

💡 Vector arithmetic works!

king − man + woman ≈ queen
This is real math on embedding vectors. The model has learned that "king" and "queen" differ only by the "gender" dimension. This is how semantic search, RAG, and recommendations work — all just distance calculations in embedding space.

09 / Transformers & Attention

Every word
watches every
other word.

The Transformer (2017, "Attention Is All You Need") revolutionised AI. Its core innovation: self-attention — each token can look at any other token in the sequence, weighted by relevance. This lets models understand long-range context in a single pass.

🔍

Analogy — Reading a detective novel: When you hit "he did it", your brain instantly links "he" back to the suspect mentioned 3 pages ago. Attention does the same — every word can "look back" at any earlier word and decide how much it matters for understanding the current word.

💡 Why it matters

"Bank" means different things in "river bank" vs "deposit at the bank". Attention lets the model look at surrounding words and disambiguate. GPT, Claude, Gemini, BERT — all Transformer-based. The 2017 paper is the single most impactful AI paper of the decade.

10 / Large Language Models

Predict the
next word.
Trillions of times.

LLMs are trained on a single objective: given all previous tokens, predict the next token. That's it. But do this on essentially all human-written text with hundreds of billions of parameters, and remarkable capabilities emerge — writing, coding, reasoning, translating — none explicitly programmed.

📱

Analogy — Autocomplete on steroids: Your phone's autocomplete was trained on your own messages and suggests next words. LLMs were trained on essentially all human knowledge, at incomparably larger scale. Same task, completely different capability that emerges from scale.

💡 Scale creates new abilities

GPT-1 (117M params, 2018): barely coherent sentences.
GPT-3 (175B params, 2020): writes essays, translates.
GPT-4 (~1.8T params est., 2023): passes bar exam, reasons about novel situations.
No one explicitly programmed these capabilities — they emerged from scale.

11 / Generative AI

AI that creates,
not just
classifies.

Traditional ML classifies (is this a cat or dog?). Generative AI produces new content — text, images, audio, code, video. Different modalities use different architectures: Transformers for text, Diffusion models for images, GANs for some video.

🎨

Diffusion models: Learn by studying noise. Training = take real images, gradually add random noise until it's pure static, teach the model to reverse the process. Inference = start with pure noise, denoise step-by-step guided by a text prompt. Midjourney, DALL-E, Stable Diffusion all use this.

💡 Four types of Generative AI

Text: GPT-4, Claude, Gemini (Transformer + RLHF)
Image: DALL-E, Midjourney, Stable Diffusion (Diffusion models)
Code: GitHub Copilot, Cursor (LLMs fine-tuned on code)
Multimodal: GPT-4o, Gemini Ultra (see, hear, and speak)

12 / Prompt Engineering

How you ask matters
as much as what you ask.

LLMs are extremely sensitive to phrasing. Prompt Engineering is the skill of designing inputs that get the best possible output. Three techniques unlock dramatically better results.

Zero-Shot

Just ask the question directly. Works for common tasks the model has seen in training. Fast, but quality varies.

Translate "Hello, how are you?" to French.
↓ Output
Bonjour, comment allez-vous ?
Best for: simple, common tasks
Few-Shot

Provide 2–5 examples of the pattern you want. The model infers the rule from your examples. Dramatically improves consistency.

Tweet: "Great product!" → Positive Tweet: "Broken on arrival" → Negative Tweet: "Does the job" → ?
↓ Output
Neutral
Best for: classification, formatting
Chain-of-Thought

Add "Let's think step by step" or show reasoning examples. Forces the model to reason before answering. Boosts accuracy on hard problems by 40–50%.

Q: If a train travels 60 mph for 2.5 hours, how far? Let's think step by step.
↓ Output
Speed = 60 mph. Time = 2.5 hrs. Distance = 60 × 2.5 = 150 miles.
Best for: math, reasoning, code
💡 Power tips

Be specific: "Write a Python function that..." beats "write code".
Give context: "You are a senior security engineer reviewing..." sets the role.
Specify format: "Return a JSON object with keys: name, score, reason".
Constrain length: "In 3 bullet points" prevents 10-page essays.

13 / Agentic AI

AI that acts,
not just
answers.

Traditional LLMs answer one question per call. AI Agents combine LLMs with tools (search, code execution, APIs, browser) and run in a loop — thinking, acting, observing results, repeating — to complete complex multi-step tasks autonomously.

👷

Analogy — Consultant vs Employee: Asking a one-shot LLM is like a consulting call: one question, one answer. An AI Agent is like a full-time employee with access to tools: they receive a goal, break it into steps, use whatever tools needed, and report back when done.

💡 The Agent Loop

Perceive: Read the task and current context
Think: Reason about what needs to be done next
Act: Call a tool (search, run code, write file, call API)
Observe: Read the tool's output, update context
Repeat until the task is complete.

Examples: Claude computer use, GitHub Copilot Workspace, Devin AI, AutoGPT.
