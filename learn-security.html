01 / What is Cybersecurity?

Protect data,
systems, and
people.

Cybersecurity is the practice of protecting systems, networks, and data from digital attacks, theft, and damage. It's not just about firewalls — it's about people, processes, and technology working together to reduce risk.

🏰

Analogy — Castle defence: A medieval castle didn't rely on just a moat. It had walls, guards, a drawbridge, a keep, and watchtowers. Cybersecurity works the same way — multiple overlapping layers of defence. If one fails, the next layer holds.

💡 The CIA Triad

Confidentiality: Only authorised people can read the data (encryption, access control).
Integrity: Data hasn't been tampered with (checksums, signing).
Availability: Systems are accessible when needed (redundancy, DDoS protection).
Every security decision maps to one or more of these three.

02 / Common Threats

Know your
enemy.

Most breaches exploit a small set of well-known attack patterns. Understanding these lets you design defences proactively — before attackers find them in your system.

🎣

Phishing: Like fishing — cast a fake "official" email as bait, wait for someone to click. The most common attack vector (90%+ of breaches start with phishing). No exploit needed — humans are the vulnerability.

🎣

Phishing

Fake emails/pages that steal credentials. Counter: MFA, user training, email filtering.

💉

SQL Injection

Malicious SQL in user input that hijacks database queries. Counter: parameterised queries, ORMs.

🔁

XSS

Injecting JavaScript into pages viewed by others. Counter: output encoding, CSP headers.

🔐

Credential Stuffing

Using leaked username/password pairs on other sites. Counter: MFA, breach monitoring.

03 / Authentication vs Authorisation

Who are you?
What can
you do?

Authentication (AuthN) proves identity. Authorisation (AuthZ) decides permissions. These are two separate steps — you must be authenticated before your authorisation is checked.

🎫

Analogy — Concert venue:
Authentication = showing your ID at the door ("prove you are who you say you are")
Authorisation = your ticket type determines where you can sit — floor, balcony, backstage
The bouncer checks ID first, then ticket type. Same order in software.

💡 MFA makes AuthN much stronger

Multi-Factor Authentication requires two or more of:
Something you know — password
Something you have — phone / hardware token
Something you are — fingerprint / face
A stolen password alone isn't enough when MFA is on.

04 / Encryption

Scramble data
so only the
right key works.

Encryption transforms readable data (plaintext) into unreadable noise (ciphertext) using a mathematical key. Without the correct key, the data is useless to an attacker — even if they intercept it.

📮

Analogy — Padlock box:
Symmetric encryption = one key opens and locks (AES). Fast. Both sides need the same key.
Asymmetric encryption = public key locks, private key unlocks (RSA, ECC). Solves key exchange. HTTPS uses asymmetric to share a symmetric key.

💡 HTTPS in 3 steps

1. Browser downloads server's public key (TLS certificate)
2. Browser generates a random session key, encrypts it with the public key → sends to server
3. Server decrypts session key with its private key → both sides now share a secret
All page data is then encrypted with that fast symmetric session key.

05 / Defence in Depth

Many layers.
No single point of failure.

No single security control is perfect. Defence in depth stacks multiple independent controls so that if one is bypassed, others still protect the system — attackers must defeat every layer.

🌐

Perimeter

Firewall, WAF (Web Application Firewall), DDoS protection. First line — filter bad traffic before it reaches your systems.

Block by IP · Rate limit · Geo-filter
🔐

Identity & Access

Strong passwords + MFA. Principle of least privilege. Zero-trust: verify every request, trust nothing by default.

SSO · MFA · Short-lived tokens
🔍

Detection & Response

Even with the best prevention, assume breach. SIEM collects logs. Alerts on anomalies. Incident response playbooks.

SIEM · EDR · Threat intel feeds
🧱

Application Security

Secure coding practices, code review, dependency scanning, SAST/DAST tools. Fix vulnerabilities before production.

OWASP Top 10 · Snyk · SonarQube
🗄️

Data Security

Encrypt data at rest and in transit. Data classification. Backups. Data loss prevention (DLP). GDPR compliance.

AES-256 · TLS 1.3 · Key rotation
🧑‍💻

People & Process

Security training, phishing simulations, patch management policies. 90%+ of breaches involve human error. Culture matters most.

Training · Drills · Bug bounty
